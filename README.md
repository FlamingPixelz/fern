# React Prototype

This project implements the main "dashboard" screen as described by the wireframe design [here](./Wireframe/597916405-8e834179-d3d5-4b74-b023-38e36c835a50.png).

To run the project on any platform, the following steps can be taken:

1. Ensure that [Node.js](https://nodejs.org/en) is installed.
2. Navigate to the app directory, if you are in the root directory of the repository, use: `cd app`.
3. Install the app's dependencies with `npm install`.
4. Run the app with `npm start`. It should automatically open a browser to the dashboard page. Alternatively, the app runs on port 3000 if nothing else is, so it can be navigated to with the address [http://localhost:3000](http://localhost:3000).
